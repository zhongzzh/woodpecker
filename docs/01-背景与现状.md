# 01 背景与现状

（记录时间：2026-07-13）

## 1. 角色与场景

- 用户是测试实习生，负责数学函数库的**函数测试**（功能 + 性能）。
- 被测对象：git.tongyuan.cc 上的 Julia 数学库，目前涉及四个仓库：
  TyComputationalGeometry.jl、TyGraphTheory.jl、TyMathCore.jl、TyOptimCore.jl
  （路径形如 `syslab/packages/math/<库名>.jl`）。
- 开发通过 GitLab Merge Request 提交变更，每周汇总成一封"周提测"邮件发给测试组。

## 3. 任务类型

| 类型 | 本期例子 | 测试侧要做的事（初步理解，待 03-G 确认） |
| --- | --- | --- |
| 新增函数 | surfaceArea、labeledge/labelnode、pagenorm | 读文档 → 核对单测覆盖缺口 → 补写用例；看性能报告判定 |

## 4. 当前人工流程

1. 收邮件，逐行认领任务。
2. 打开 MR 链接，找到源分支，`git clone` + `git checkout` 到对应分支。
3. 在仓库里找到：函数文档（md）、开发写的单元测试、性能报告（MR note）。
4. 以文档为准逐条核对单测覆盖，找遗漏，补写用例。**开发写的内容一律不动。**
5. 读性能报告，按标准判定通过/不通过。
6. 汇总成测试结论。
