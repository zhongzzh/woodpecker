### 文档自身缺陷审计

- `nargout` 是公开语法中的用户可设置参数，却未列入“输入参数”章节。
- 文档只展示 `nargout=Val(2)`，没有说明省略时的默认值，也没有说明是否支持显式 `nargout=Val(1)`；现有异常测试中的消息却声明仅允许 `Val(1)` 或 `Val(2)`。
- `RegionID` 被声明为整数，但现有测试明确接受整数值浮点标量 `1.0`，文档与已测试行为不一致。
- “整数”没有明确对应 Julia 的 `Integer` 全部子类型、仅 `Int`，还是所有取整数值的 `Real`。
- “整数数组”没有说明允许的数组维数、是否接受范围对象、矩阵及更高维数组。现有测试已经使用范围、矩阵、重复 ID 和乱序 ID。
- 没有说明重复 RegionID 是否去重、输出是否按区域编号排序，以及输入顺序是否影响输出；现有测试实际断言了去重和顺序无关行为。
- 没有说明空 alphaShape、二维共线点和三维共面点的返回约定。
- `RegionID` 的范围约束虽然清楚，但没有说明空数组是否有效。

### 覆盖缺口与优先级

**高优先级**

- `RegionID` 的其他 `Signed` 类型、`Unsigned` 类型和相应数组未覆盖。现有证据全部使用默认 `Int`，不足以证明文档笼统声明的“整数”类型范围；建议至少增加 `Int32`、`UInt8` 和 `BigInt` 的标量及向量，并与相同 ID 的 `Int` 结果作关系断言。
- 文档将 `RegionID` 声明为整数数组但未限制维数，现有测试最高只到矩阵。建议补充三维整数数组；如果实现只支持向量或矩阵，应改正文档并增加拒绝高维数组的异常断言。

**中优先级**

- 显式 `nargout=Val(1)` 没有构造、调用和结果断言，默认调用不能替代该证据。异常消息却把 `Val(1)` 列为合法值；建议增加显式调用与默认结果的等值断言，并在文档中公开该形式。
- `RegionID=1.0` 已被测试为成功，但文档仅声明整数。应决定这是兼容行为还是公开契约；前者应在文档中说明“取整数值的实数”，后者应将测试改为异常契约。覆盖审计不能仅凭现有成功测试推断文档允许 Float64。
- 重复、乱序和矩阵 RegionID 的行为已有测试，但文档没有描述去重、排序及展平规则。建议补齐规范，避免测试锁定未公开的偶然行为。

**低优先级**

- 空对象和退化对象虽然有精确空结果断言，但这些是弱边界场景，不能代表一般 alphaShape。非空二维和三维已有强证据；建议仅补充文档中的空结果约定。
- 文档没有说明空 RegionID 数组的有效性。应先确定预期语义，再使用结果性质或异常断言补测，不能在缺少规范或 baseline 时编造精确结果。
- 所有明确点数据均为 Float64。由于 `alphaTriangulation` 接收的是 alphaShape 对象而非原始点矩阵，这不构成直接参数类型缺口，但若 alphaShape 保留不同坐标元素类型，则可另行进行集成覆盖。

@testset "alphaTriangulation 补充覆盖" begin
    points = [
        0.0 0.0
        2.0 0.0
        0.0 2.0
        10.0 0.0
        11.0 0.0
        10.0 1.0
        20.0 0.0
        20.4 0.0

    ]

    tri_region1 = alphaTriangulation(shp, 1)
    tri_all = alphaTriangulation(shp, 1:3)
    tri_default = alphaTriangulation(shp)

    @test alphaTriangulation(shp, Int32(1)) == tri_region1
    @test alphaTriangulation(shp, UInt8(1)) == tri_region1
    @test alphaTriangulation(shp, big(1)) == tri_region1

    @test alphaTriangulation(shp, Int32[1, 2, 3]) == tri_all
    @test alphaTriangulation(shp, UInt8[1, 2, 3]) == tri_all
    @test alphaTriangulation(shp, BigInt[1, 2, 3]) == tri_all

    region_ids_3d = reshape(Int32[1, 2, 3], 1, 1, 3)
    @test alphaTriangulation(shp, region_ids_3d) == tri_all

    tri_val1 = alphaTriangulation(shp; nargout=Val(1))
    @test tri_val1 == tri_default
end
