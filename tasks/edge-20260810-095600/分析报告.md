### 覆盖缺口与优先级

**高优先级**

- **Roberts 方法 + direction="horizontal" / direction="vertical"**：文档声明 Roberts 方法可以检测与水平方向成 45°/135° 角的边缘，但现有测试中 Roberts 仅测试了默认 both 方向，未单独传入 direction 参数验证其方向性行为。建议补测 Roberts 分别传入 "horizontal" 和 "vertical" 的场景。
- **"log" 方法 + threshold=0 的特殊行为**：文档明确声明“对于 log 和 zerocross 方法，如果您指定阈值 0，则输出图像具有闭合轮廓”，现有测试未覆盖此行为。建议补测 log 和 zerocross 在 threshold=0 时的闭合轮廓性质。
- **Zerocross 方法的结果断言为弱证据**：补充测试中 `zerocross_result isa AbstractMatrix` 和 `size(zerocross_result) == size(gray_image)` 仅为类型/尺寸断言，缺少具体的边缘位置真值验证。建议在有 baseline 图像的条件下补充精确断言。

**中优先级**

- **Canny 方法 + direction 参数的异常行为**：文档未显式说明 Canny 传入 direction 的行为，但实现代码中 `_edge_dispatch(::Val{:canny}, ...)` 忽略 direction 参数，不会报错。测试中未覆盖 Canny + direction 的场景，建议补测以确认是静默忽略还是应报错。
- **"zerocross" 方法 + 空 threshold 默认行为**：`zerocross` 传入空数组 `[]` 的自动阈值行为未独立测试，现有测试仅在非空阈值下覆盖。建议补测 zerocross 不传 threshold 或传空数组的场景。
- **Float64 类型的 sigma 对 log 方法**：补充测试中 log + sigma=1.0 的结果断言使用了 `expected_log` 矩阵，但该预期值来自与原测试相同的 `sigma=1`（整数）数据，并非独立验证 Float64 路径的预期结果。需要确认 `sigma=1.0` 和 `sigma=1` 是否产生相同结果。

**低优先级**

- **极小图像 + 各方法的边界行为**：现有测试覆盖了 `zeros(2,2)` 对 Canny 和 zerocross 的测试，但未系统覆盖所有方法（如 Sobel、Prewitt、Roberts、log）在 2×2 或更小图像上的行为。
- **Canny 方法 + threshold 为单元素向量的边界**：`selectThresholds` 中 `_edge_threshold_length(threshold) == 1` 的分支通过 `_edge_scalar_threshold` 提取 `first(threshold)`，测试中未覆盖传入 `[0.5]` 单元素向量的场景。

@testset "edge 补充" begin
    # 复用原测试中 step_image 的数据构造方式
    step_mask = falses(7, 7)
    step_mask[:, 5:end] .= true
    step_image = Float64.(step_mask)

    @testset "Roberts method with explicit direction" begin
        # Roberts horizontal: 检测与水平方向成 135° 角的边缘
        roberts_h = edge(step_image, "Roberts"; direction="horizontal", threshold=0.1, fig=false)
        @test roberts_h isa BitMatrix
        @test size(roberts_h) == size(step_image)
        # 方向过滤后应至少有一个边缘点，且不同于 both
        roberts_both = edge(step_image, "Roberts"; direction="both", threshold=0.1, fig=false)
        @test roberts_h != roberts_both
        @test any(roberts_h)

        # Roberts vertical: 检测与水平方向成 45° 角的边缘
        roberts_v = edge(step_image, "Roberts"; direction="vertical", threshold=0.1, fig=false)
        @test roberts_v isa BitMatrix
        @test size(roberts_v) == size(step_image)
        @test roberts_v != roberts_both
        @test any(roberts_v)

        # horizontal 和 vertical 对 Roberts 应产生不同结果
        @test roberts_h != roberts_v
    end

    @testset "log and zerocross with threshold=0" begin
        # threshold=0 应产生闭合轮廓（包含所有过零点）
        log_zero = edge(step_image, "log"; threshold=0.0, sigma=1.0, fig=false)
        zerocross_zero = edge(step_image, "zerocross"; threshold=0.0, sigma=1.0, fig=false)
        @test log_zero isa BitMatrix
        @test zerocross_zero isa BitMatrix
        @test size(log_zero) == size(step_image)
        @test size(zerocross_zero) == size(step_image)
        # 闭合轮廓意味着存在边缘点
        @test any(log_zero)
        @test any(zerocross_zero)
        # 阈值 0 的边缘点应不少于阈值 0.01 的结果
        log_pos = edge(step_image, "log"; threshold=0.01, sigma=1.0, fig=false)
        zerocross_pos = edge(step_image, "zerocross"; threshold=0.01, sigma=1.0, fig=false)
        @test sum(log_zero) >= sum(log_pos)
        @test sum(zerocross_zero) >= sum(zerocross_pos)
    end

    @testset "zerocross with empty threshold (default)" begin
        result = edge(step_image, "zerocross"; threshold=Float64[], sigma=1.0, fig=false)
        @test result isa BitMatrix
        @test size(result) == size(step_image)
        @test any(result)
    end

    @testset "Canny with direction parameter (silently ignored)" begin
        # 文档未声明 Canny 支持 direction，但实现忽略该参数不报错
        canny_result, _ = edge(step_image, "Canny"; direction="horizontal", sigma=1.0, fig=false)
        @test canny_result isa BitMatrix
        @test size(canny_result) == size(step_image)
    end

    @testset "Canny with single-element vector threshold" begin
        canny_result, thresholds = edge(
            step_image, "Canny"; threshold=[0.5], sigma=1.0, fig=false
        )
        @test canny_result isa BitMatrix
        @test size(canny_result) == size(step_image)
