### 文档自身缺陷审计

- 示例 3 写有 `imshow（I）`，为全角括号笔误，应为 `imshow(I)`。
- `NumLevels` 文档写“正整数”，算法与实现允许 `NL == 0`（得到空 GLCM），解析错误文案为 non-negative，正/非负约束不一致。
- `NumLevels`、`GrayLimits` 的默认值主要写在“算法”而非名称-值参数正文（灰度默认 8、二值默认 2；`GrayLimits` 默认类范围），名称-值节不完整。
- `I` 声明类型仅 Float64/UInt8/UInt16/Int16/Bool，实现为 `AbstractMatrix{<:Real}`，文档类型集合可能偏窄且未说明其它 Real 是否支持。
- `GrayLimits` 在 `[]` 与“类默认范围”两段叙述易混：`[]` 用 `min/max(I)`，非空默认路径才是类范围（如 double 的 [0,1]）。
- 文档示例给出具体 `glcm`/`SI` 数值，但测试未用这些数值做断言，文档与测试未形成可核对真值闭环。
- 名称-值示例写 `graycomatrix(I,Offset=[2 0])`（逗号），与正文 `Name=Value`/分号风格不一致。

### 覆盖缺口与优先级

**高优先级**

- `I`：UInt8、UInt16、Int16、Bool 均无“构造/加载 + 调用 + 结果断言”。imread 不能代替元素类型覆盖。建议用 `UInt8`/`UInt16`/`Int16` 小矩阵及 `Bool` 矩阵补测，并断言 `size(glcm)`、`eltype`、`extrema(SI)`。
- `GrayLimits` 非空 `[low high]`：无任何用例。建议固定小矩阵，设明确 `[low high]` 与 `NumLevels`，断言 `SI` 落在 `1:NumLevels` 且边界映射符合文档（≤low→1，≥high→NumLevels）。
- 结果断言过弱：现有仅 `typeof` 输出。建议至少断言 `size(glcm,1)==NumLevels`、多偏移 `size(glcm,3)==p`，`Symmetric=true` 时 `glcm ≈ glcm'`。

**中优先级**

- `NumLevels` 与 Bool 约束：二值图默认 2 级未测；可选断言 `eltype(I)==Bool` 且 `NumLevels!=2` 时报错（若纳入行为覆盖）。
- 文档示例数值未入库：`NumLevels=9, GrayLimits=[]` 与 `Offset=[2 0]` 等可用文档表格做 baseline，当前测试未用。
- 单偏移挤压为矩阵、多偏移为 3D 的形状分支未显式断言。

**低优先级**

- 默认 `Offset=[0 1]`、`Symmetric=false` 仅隐式默认路径，可各加一组显式 `false`/`[0 1]` 对照。
- `GrayLimits` 使 `low==high` 时 `SI` 全 1 的实现分支未测。
- NaN/Inf 像素对、越界邻域忽略等算法分支文档有述但非“用户输入类型”主清单，可作扩展。

using TyImageProcessing, Test

@testset "graycomatrix" begin
    @testset "src" begin
        I = imread("circuit.tif")
        glcm, SI = graycomatrix(I; Offset=[2 0])
        @test typeof(glcm) <: AbstractArray{Float64} && typeof(SI) <: AbstractArray{Float64}

        I = [1.0 1 5 6 8 8; 2 3 5 7 0 2; 0 2 3 5 6 7]
        glcm, SI = graycomatrix(I; NumLevels=9, GrayLimits=Float64[])
        @test typeof(glcm) <: AbstractArray{Float64} && typeof(SI) <: AbstractArray{Float64}

        I = imread("cell.tif")
        offsets = [0 1; -1 1; -1 0; -1 -1]
        glcm, SI = graycomatrix(I; Offset=offsets)
        @test typeof(glcm) <: AbstractArray{Float64} && typeof(SI) <: AbstractArray{Float64}

        I = imread("circuit.tif")
        glcm, SI = graycomatrix(I; Offset=[2 0], Symmetric=true)
        @test typeof(glcm) <: AbstractArray{Float64} && typeof(SI) <: AbstractArray{Float64}
    end

    @testset "input types and structures gaps" begin
        # I: Float64 小矩阵 — 形状与 SI 范围（补强原弱证据）
        I_f64 = [1.0 1 5 6 8 8; 2 3 5 7 0 2; 0 2 3 5 6 7]
        glcm_f64, SI_f64 = graycomatrix(I_f64; NumLevels=9, GrayLimits=Float64[])
        @test eltype(I_f64) == Float64
        @test size(glcm_f64) == (9, 9)
        @test size(SI_f64) == size(I_f64)
        @test eltype(glcm_f64) == Float64 && eltype(SI_f64) == Float64
        @test all(1 .<= SI_f64 .<= 9)

        # I: UInt8
        I_u8 = UInt8[0 1 2 3; 1 2 3 4; 2 3 4 5]
        glcm_u8, SI_u8 = graycomatrix(I_u8; NumLevels=4, Offset=[0 1])
        @test eltype(I_u8) == UInt8
        @test size(glcm_u8) == (4, 4)
        @test size(SI_u8) == size(I_u8)
        @test all(1 .<= SI_u8 .<= 4)

        # I: UInt16
        I_u16 = UInt16[10 20 30; 20 30 40; 30 40 50]
        glcm_u16, SI_u16 = graycomatrix(I_u16; NumLevels=5, Offset=[0 1])
        @test eltype(I_u16) == UInt16
        @test size(glcm_u16) == (5, 5)
        @test size(SI_u16) == size(I_u16)
        @test all(1 .<= SI_u16 .<= 5)

        # I: Int16
        I_i16 = Int16[0 10 20; 10 20 30; 20 30 40]
        glcm_i16, SI_i16 = graycomatrix(I_i16; NumLevels=4, GrayLimits=[0, 40], Offset=[0 1])
        @test eltype(I_i16) == Int16
        @test size(glcm_i16) == (4, 4)
        @test size(SI_i16) == size(I_i16)
        @test all(1 .<= SI_i16 .<= 4)

        # I: Bool / 逻辑二维矩阵（默认 NumLevels=2）
        I_bool = Bool[0 1 1 0; 1 1 0 0; 0 0 1 1]
        glcm_b, SI_b = graycomatrix(I_bool; Offset=[0 1])
        @test eltype(I_bool) == Bool
        @test size(glcm_b) == (2, 2)
        @test size(SI_b) == size(I_bool)
        @test all(SI_b .== 1 .|| SI_b .== 2)

        # GrayLimits: 显式非空二元向量 [low high]
        I_gl = [0.0 0.5 1.0; 0.25 0.75 1.0; 0.0 0.5 0.25]
        glcm_gl, SI_gl = graycomatrix(I_gl; NumLevels=4, GrayLimits=[0.0, 1.0], Offset=[0 1])
        @test size(glcm_gl) == (4, 4)
        @test all(1 .<= SI_gl .<= 4)
        # 边界映射：≤low → 1，≥high → NumLevels（性质断言）
        I_bound = [0.0 1.0; -1.0 2.0]
        _, SI_bound = graycomatrix(I_bound; NumLevels=8, GrayLimits=[0.0, 1.0], Offset=[0 1])
        @test SI_bound[1, 1] == 1.0
        @test SI_bound[1, 2] == 8.0
        @test SI_bound[2, 1] == 1.0
        @test SI_bound[2, 2] == 8.0

        # NumLevels: 显式 8；Offset 默认 [0 1] 形状
        I_nl = Float64[1 2 3; 2 3 4; 3 4 5]
        glcm_nl, SI_nl = graycomatrix(I_nl; NumLevels=8)
        @test size(glcm_nl) == (8, 8)
        @test ndims(glcm_nl) == 2
        @test all(1 .<= SI_nl .<= 8)

        # Offset: p×2 第三维；单偏移为矩阵非 3D
        offs = [0 1; -1 0]
        glcm_m, SI_m = graycomatrix(I_nl; NumLevels=4, Offset=offs)
        @test size(glcm_m) == (4, 4, 2)
        @test size(SI_m) == size(I_nl)
        glcm_s, _ = graycomatrix(I_nl; NumLevels=4, Offset=[0 1])
        @test size(glcm_s) == (4, 4)
        @test ndims(glcm_s) == 2

        # Symmetric: true 时关于对角线对称；显式 false
        glcm_sym, _ = graycomatrix(I_nl; NumLevels=4, Offset=[0 1], Symmetric=true)
        @test size(glcm_sym) == (4, 4)
        @test glcm_sym ≈ transpose(glcm_sym)
        glcm_ns, _ = graycomatrix(I_nl; NumLevels=4, Offset=[0 1], Symmetric=false)
        @test size(glcm_ns) == (4, 4)
        @test eltype(glcm_ns) == Float64

        # imread 路径：补 eltype/形状性质（不猜测具体数值真值）
        I_img = imread("circuit.tif")
        @test I_img isa AbstractMatrix
        @test eltype(I_img) <: Union{Real,Bool}
        glcm_img, SI_img = graycomatrix(I_img; Offset=[2 0], NumLevels=8)
        @test size(glcm_img, 1) == 8 && size(glcm_img, 2) == 8
        @test size(SI_img) == size(I_img)
        @test all(1 .<= SI_img .<= 8)
    end
end
