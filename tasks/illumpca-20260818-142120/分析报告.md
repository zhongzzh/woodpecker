### 覆盖缺口与优先级

高优先级

- `percentage` 缺少 Int8、Int16、Int32、UInt8、UInt16、UInt32 六种文档声明类型。现有 Int64、Float32、Float64、UInt64 证据不能替代其他具体标量类型；应使用相同合法值逐类型构造、调用，并与 Float64 参考调用比较输出类型、形状和数值一致性。

中优先级

- Float32 图像只有全零退化样本。虽然已有构造、调用和结果断言，但未验证一般非零 Float32 图像的 PCA 路径；建议增加非恒定 Float32 RGB 数组，并至少断言输出形状、Float64 元素类型、有限性以及与对应 Float64 图像的合理一致性。
- 数值掩膜只使用 0 和 1。文档措辞允许一般数值矩阵，而实现将任意非零值视为包含；建议增加包含负数及大于 1 数值的掩膜，并验证其与对应 Bool 非零模式结果一致。
- 文档未公开 A 的非空、三维三通道、有限且非 NaN 约束，以及 Mask 的非空、二维、尺寸匹配、非 NaN 和至少一个非零值约束；建议先完善文档，再按公开约束系统补齐边界测试。

低优先级

- 图片加载用例没有断言 `A` 或 `A_lin` 的元素类型，不能作为某一输入类型的稳定覆盖证据；如需将集成样例纳入类型覆盖，应增加明确类型断言，但该断言会依赖图像读取和转换接口的稳定约定。
- `percentage=50` 目前只有形状断言，能够证明边界可调用，但不能证明该分支的数值正确性；建议在获得可信 baseline 后增加数值回归断言。
- 默认 Mask 没有与显式全 true 掩膜直接比较；建议增加等价性断言，以强化“默认全为 1”的公开声明。

@testset "illumpca 补充" begin
    @testset "percentage 缺失标量类型" begin
        A = reshape(Float64.(1:144) ./ 144, 8, 6, 3)
        reference = illumpca(A, Float64(10))

        @test size(reference) == (1, 3)
        @test eltype(reference) == Float64
        @test all(isfinite, reference)

        for T in (Int8, Int16, Int32, UInt8, UInt16, UInt32)
            percentage = T(10)
            illuminant = illumpca(A, percentage)

            @test size(illuminant) == (1, 3)
            @test eltype(illuminant) == Float64
            @test all(isfinite, illuminant)
            @test isapprox(illuminant, reference; rtol=1e-12, atol=0.0)
        end
    end

    @testset "Mask 缺失数值矩阵类型" begin
        A = reshape(Float64.(1:144) ./ 144, 8, 6, 3)
        logicalMask = trues(8, 6)
        logicalMask[2:4, 3:5] .= false
        reference = illumpca(A, 10; Mask=logicalMask)

        @test size(reference) == (1, 3)
        @test eltype(reference) == Float64
        @test all(isfinite, reference)

        for T in (Float32, Int8, Int16, Int32, Int64, UInt8, UInt16, UInt32, UInt64)
            numericMask = T.(logicalMask)
            illuminant = illumpca(A, 10; Mask=numericMask)

            @test size(illuminant) == (1, 3)
            @test eltype(illuminant) == Float64
            @test all(isfinite, illuminant)
            @test isapprox(illuminant, reference; rtol=1e-12, atol=0.0)
        end
    end
end
