### 文档自身缺陷审计

- 文档没有明确说明 `A` 必须非空、不得包含 `NaN` 且所有值必须有限，但实现会拒绝空数组、`NaN` 和无穷值。

- 文档没有说明 `Mask` 必须非空、必须恰好为二维且不得包含 `NaN`；这些均是实现中的显式约束。
- 文档没有说明显式 `Mask` 的行列数必须与 `A` 的前两维一致。
- 文档没有说明 `Mask` 至少要包含一个非零元素；全零掩膜会因没有可用像素而抛出异常。
- `percentage` 和 `Mask` 的公开类型列表比函数签名更窄。实现签名分别接受任意 `Real` 和任意实数数组，随后并未按照文档列表逐项限制其元素类型，因而文档与实现的实际可接收类型范围可能不一致。

### 缺失测试代码补全

```julia
@testset "illumpca 补充" begin
    @testset "percentage 缺失类型" begin
        A = reshape(Float64.(1:144) ./ 144, 8, 6, 3)
        reference = illumpca(A, Float64(10))

        for T in (Int8, Int16, Int32, UInt8, UInt16, UInt32)
            percentage = T(10)
            illuminant = illumpca(A, percentage)
            @test size(illuminant) == (1, 3)
            @test eltype(illuminant) == Float64
            @test all(isfinite, illuminant)
            @test illuminant ≈ reference
        end
    end

    @testset "Mask 缺失类型" begin
        A = reshape(Float64.(1:144) ./ 144, 8, 6, 3)
        logical_mask = trues(8, 6)
        logical_mask[2:4, 3:5] .= false
        reference = illumpca(A, 10; Mask=logical_mask)

        for T in (Float32, Int8, Int16, Int32, Int64, UInt8, UInt16, UInt32, UInt64)
            numeric_mask = T.(logical_mask)
            illuminant = illumpca(A, 10; Mask=numeric_mask)
            @test size(illuminant) == (1, 3)
            @test eltype(illuminant) == Float64
            @test all(isfinite, illuminant)
            @test illuminant ≈ reference
        end
    end
end
```
