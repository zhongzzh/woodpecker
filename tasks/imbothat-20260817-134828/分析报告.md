- 缺失 SE 的 UInt8 二维数值矩阵：文档明确列出 UInt8 数据类型，但所有有效 SE 测试均使用 Bool。现有 `[0 2;1 0]` 是 Int64 且包含 2，触发异常，不能替代有效 UInt8 0/1 矩阵。建议补测 UInt8 方阵、菱形、非对称矩阵，并断言结果与等价 Bool SE 一致。

中优先级：

- 缺失 I 的一维向量和四维及以上数组：文档写“任意维度”，实现只支持 2D/3D。现有 `row_signal` 是 1×5 矩阵而非 1D。建议修订文档为 2D/3D，或扩展实现后补测。
- 缺失 SE 非 0/1 数值行为的文档约束：实现会对非 0/1 的整数 SE 报错，但文档未说明。建议补充约束。

- 单点 SE 与全零 SE 属于边界弱证据，可继续增加更大形态或更复杂的非中心结构元素测试。
- 三维 UInt8 SE 未覆盖，但文档未要求 3D SE，不属于文档缺口；如实现继续支持 3D SE，可考虑补充。
