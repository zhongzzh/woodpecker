- 文档称支持“任意数量”的移动图像，但没有明确至少需要一个移动图像和一个固定图像，也没有说明最后一个位置参数始终解释为 `F`。

- 实现要求输入非空、为实数、不含 `NaN` 且全部有限，文档未声明这些约束。
- 文档没有明确灰度图像究竟仅允许二维矩阵，还是也允许第三维长度为 1 的数组；实现同时接受这两种形式。

- 文档只列出浮点数据类型，没有说明 `Float32`、`Float64` 图像的推荐或有效数值范围；实现会先转换为 `UInt8`，数值范围会影响转换语义。

### 覆盖缺口与优先级

**高优先级**

- 四种元素类型的 RGB 结构均缺少明确的 `size(image, 3) == 3` 证据；现有 `ndims(Iu8) == 3` 也可能对应单通道三维数组。建议构造确定的三通道数组，对移动图像和固定图像分别断言元素类型、维数和通道数后调用。
- `UInt8` RGB 输入还缺少元素类型证据；根据规则不能从 `imread` 返回值猜测其元素类型。建议使用显式 `UInt8` 数组覆盖。
- 可变曝光没有明确构造证据。建议从同一非均匀图像生成亮度偏移版本，断言输入确实不同，并验证返回图像及位移矩阵的类型、形状和有限性。

**中优先级**

- `UInt8` 二维灰度输入的明确证据主要来自异常调用，正常成功调用依赖未断言类型的加载结果。建议增加显式 `Matrix{UInt8}` 的非均匀有效图像成功测试。
- 多移动图像只覆盖 `n=5`，单移动图像只覆盖 `n=1`。这足以证明两种调用形式存在，但不能说明不同数量下输出数量始终正确；可根据实际风险增加 `n=2` 边界样本。
- 尺寸不匹配测试只断言捕获到异常，没有断言异常类型或消息，可能掩盖与目标约束无关的错误。建议至少验证尺寸错误消息。

**低优先级**

- 同曝光测试全部使用完全相同的图像，属于零位移单点。可增加同曝光但非零平移的性质测试；精确位移需要可信 baseline。
- 实现中的空输入、`NaN`、`Inf`、复数、错误通道数和少于两个位置参数等行为没有测试。它们未在当前文档中公开，因此不计入文档要求覆盖率，但应在文档补全后同步补测。

@testset "imregmtb 补充" begin
    grayU8 = reshape(UInt8.(mod.(0:(64 * 64 - 1), 251)), 64, 64)
    exposedGrayU8 = UInt8.(clamp.(Int.(grayU8) .+ 12, 0, 255))

    @testset "UInt8 灰度正常路径" begin
        @test grayU8 isa Matrix{UInt8}
        @test exposedGrayU8 isa Matrix{UInt8}
        @test size(grayU8) == size(exposedGrayU8)
        @test grayU8 != exposedGrayU8

        registered, shift = imregmtb(exposedGrayU8, grayU8)

        @test size(registered) == size(exposedGrayU8)
        @test eltype(registered) == UInt8
        @test shift isa Matrix{Float64}
        @test size(shift) == (1, 2)
        @test all(isfinite, shift)
    end

    rgbU8 = cat(
        grayU8,
        circshift(grayU8, (3, 5)),
        reverse(grayU8; dims=1);
        dims=3,
    )
    exposedRgbU8 = UInt8.(clamp.(Int.(rgbU8) .+ 12, 0, 255))
    rgbU16 = UInt16.(rgbU8) .* UInt16(257)
    exposedRgbU16 = UInt16.(exposedRgbU8) .* UInt16(257)
    rgbF32 = Float32.(rgbU8) ./ Float32(255)
    exposedRgbF32 = Float32.(exposedRgbU8) ./ Float32(255)
    rgbF64 = Float64.(rgbU8) ./ 255.0
    exposedRgbF64 = Float64.(exposedRgbU8) ./ 255.0

    rgbCases = (
        ("UInt8", exposedRgbU8, rgbU8, UInt8),
        ("UInt16", exposedRgbU16, rgbU16, UInt16),
        ("Float32", exposedRgbF32, rgbF32, Float32),
        ("Float64", exposedRgbF64, rgbF64, Float64),
    )

    for (label, moving, fixed, expectedType) in rgbCases
        @testset "$label RGB 可变曝光" begin
            @test ndims(moving) == 3
            @test ndims(fixed) == 3
            @test size(moving, 3) == 3
            @test size(fixed, 3) == 3
            @test size(moving) == size(fixed)
            @test eltype(moving) == expectedType
            @test eltype(fixed) == expectedType
            @test moving != fixed

            registered, shift = imregmtb(moving, fixed)

            @test size(registered) == size(moving)
            @test eltype(registered) == expectedType
            @test shift isa Matrix{Float64}
            @test size(shift) == (1, 2)
            @test all(isfinite, shift)
        end
    end
end
