### 覆盖缺口与优先级

**高优先级**

- `angle` 声明为 `Real`，现有测试却只传入 `Int` 字面量；缺少非整数 `Float32`、`Float64` 的构造、调用和结果断言，无法证明常见浮点角度输入。
- 文档声称分类图像使用 `missing` 填充并返回分类数组，但测试仅有被注释的分类数组代码，公开实现也不接受该输入；应先明确产品要求，再选择补充实现与测试或修正文档。

**中优先级**

- 缺少零角度测试；现有正负角度不能证明 `angle == 0` 的恒等旋转行为，建议使用显式矩阵并断言结果与输入相等。
- 彩色图像测试依赖 `imread("coffee")`，没有类型和维数断言；建议使用本地显式构造的三维 `Array{UInt8,3}`，断言输出元素类型、维数及 `"crop"` 尺寸。
- 缺少 `Rational` 等其他 `Real` 代表类型；建议至少选取一种可安全转换为 `Float64` 的非浮点 `Real`，以验证文档宽泛类型声明。

**低优先级**

- 当前没有针对关键字 `method=`、`bbox=` 和第三参数直接作为 bbox 的测试，但这些调用形式未在 Markdown 语法中公开；建议先补全文档，再纳入公开接口覆盖。

- `"crop"` 和 `"loose"` 已通过图片基线覆盖，但缺少直接尺寸性质断言；可增加 `size(J) == size(I)`，降低图形比较工具对尺寸问题的间接性。

    I2 = UInt8[
        1 2 3 4
        5 6 7 8

    ]

    @testset "Real角度代表类型与零角度" begin
        for angle in (Float32(12.5), Float64(-12.5), 1 // 2)
            J = imrotate(I2, angle, "nearest", "crop")
            @test J isa Matrix{UInt8}
            @test size(J) == size(I2)
        end

        I3 = collect(reshape(UInt8.(1:36), 3, 4, 3))
        J3 = imrotate(I3, Float32(15.5), "bilinear", "crop")
        @test J3 isa Array{UInt8,3}
        @test eltype(J3) == eltype(I3)
        @test ndims(J3) == 3
