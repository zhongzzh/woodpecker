**高优先级**

**中优先级**

- 尺寸一致约束只有成功路径，没有尺寸不一致异常断言；建议分别覆盖 Bool 和 Int64 标签输入的尺寸不一致。
- 非空约束完全未测试且未写入文档；建议增加空 BW1、空 BW2、空 L1、空 L2 的异常断言，并同步补充文档。

- 全假 Bool 输入的 `NaN` 行为没有测试，且与文档 `[0, 1]` 声明冲突；应先确定产品语义，再添加性质或异常断言。

@testset "jaccard 补充覆盖" begin

        @test three_dimensional_similarity == 1 / 2
    end

    @testset "Int64 一维与三维标签数组" begin

        L2_vector = Int64[0, 1, 2, 2, 0, 3]
        vector_similarity = jaccard(L1_vector, L2_vector)
        @test vector_similarity isa Matrix{Float64}
        @test size(vector_similarity) == (3, 1)
        @test vector_similarity == reshape(Float64[1 / 2, 1 / 3, 1], 3, 1)

        L2_3d = reshape(Int64[0, 1, 2, 2, 0, 0, 3, 1], 2, 2, 2)
        three_dimensional_similarity = jaccard(L1_3d, L2_3d)
        @test three_dimensional_similarity isa Matrix{Float64}
        @test size(three_dimensional_similarity) == (3, 1)
        @test three_dimensional_similarity ==
            reshape(Float64[1 / 3, 1 / 3, 1 / 2], 3, 1)
    end

    @testset "输入约束" begin
        @test_throws ErrorException jaccard(
            Bool[true, false],
            Bool[true, false, true],
        )
        @test_throws ErrorException jaccard(
            Int64[0, 1],
            Int64[0, 1, 2],
        )
        @test_throws ErrorException jaccard(
            Int64[0, -1, 1],
            Int64[0, 1, 1],
        )
        @test_throws ErrorException jaccard(
            Int64[0, 1, 1],
            Int64[0, -1, 1],
        )

        @test_throws ErrorException jaccard(Bool[], Bool[])
        @test_throws ErrorException jaccard(Bool[true], Bool[])
        @test_throws ErrorException jaccard(Int64[], Int64[])
