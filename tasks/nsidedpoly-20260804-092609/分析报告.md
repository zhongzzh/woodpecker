### 文档定义的输入参数

| 参数 | 允许形式 | 允许数据类型 | 说明 |

### 文档自身缺陷审计

- `n` 仅写“数值标量”和“有限整数”，未明确是否接受整数值浮点数、有理数、零虚部复数、任意精度整数及无符号整数。
- `Center`、`Radius` 和 `SideLength` 未明确支持哪些 Julia 实数类型，例如 `Float32`、`BigFloat`、`Rational`。
- 测试明确接受 `n=3+0im` 和 `Radius=2+0im`，但文档分别写“有限整数”和“有限正实数”，未说明零虚部复数是否属于公开支持范围。
- 文档只称 `Center` 为“向量”，未明确必须是 `AbstractVector`、是否接受元组或静态向量；现有测试表明普通元组会被拒绝。
- 文档没有说明无效参数的异常类型。现有实现测试大多期望 `ErrorException`，而结构不匹配的 `n=[3]` 期望 `MethodError`。
- 文档未说明数值转换到内部几何表示后的可表示范围。现有测试表明某些数学上有限且为正的极小值、极大值及 `BigFloat` 会因内部表示范围被拒绝。
- 示例一称默认六边形“边长为 1”。这对外接圆半径为 1 的正六边形恰好成立，但容易被误读为默认参数是 `SideLength=1`；应明确这是六边形的几何特例。
- 文档声明中心默认值为 `[0, 0]`，但未说明默认向量的元素类型，也未说明显式传入该值与省略参数是否保证完全相同的类型处理路径。

### 覆盖缺口与优先级

高优先级

- `Center` 缺少有效二元素浮点向量的成功调用和结果断言；现有浮点中心全部是无效值，不能证明文档所述有限实数坐标路径。建议使用非整数 `Float64` 中心并断言边数、质心和顶点到中心的距离。
- `Radius` 缺少有效正有限浮点标量的成功路径；默认半径和整数半径不能证明非整数浮点半径。建议使用 `Radius=2.5` 并验证质心和各顶点外接圆半径。
- 文档与测试对零虚部复数的契约不一致；现有测试把 `n=3+0im` 和 `Radius=2+0im` 当作有效输入。应明确修改文档，或将其定义为兼容行为而非公开实数类型。

中优先级

- `n` 缺少有效 `BigInt` 和无符号整数测试；已有 `BigInt` 仅验证超范围拒绝。建议用正常范围值调用并断言 `numsides`。
- `Center`、`Radius` 和 `SideLength` 缺少正常范围 `BigFloat` 测试；现有 `BigFloat` 仅验证超范围异常。建议用可转换且非整数的有限值验证成功路径。
- “有限实数”可能涵盖 `Rational`，但四个参数均未形成清晰契约。建议先明确文档；若实现承诺接受一般 `Real`，再补充整数值有理数 `n`、有理数中心和有理数尺寸。
- `SideLength` 虽覆盖 `Float32`，但没有显式 `Float64` 成功调用。建议补充 `Float64` 非整数边长并验证相邻顶点距离。
- 缺少空 `Center` 向量异常测试。建议断言 `Center=Float64[]` 被拒绝。

低优先级

- 默认中心和半径已经过 MATLAB baseline 强验证，但显式 `Center=[0.0, 0.0]`、`Radius=1.0` 的等价性未验证。可补充性质断言，避免依赖新增精确顶点 baseline。
- 文档未说明错误类型及内部可表示范围。建议记录参数验证抛出的异常契约，并解释为何某些数学上有限的值会被拒绝。
- 新增数值类型测试若只验证边数、质心、半径或边长，只能证明几何性质，不能证明顶点起始位置、绕序和逐点 MATLAB 兼容性；这些细节仍需 baseline。

### 缺失测试代码补全

```julia
@testset "nsidedpoly 补充覆盖" begin
    @testset "有效浮点 Center 和 Radius" begin
        center = Float64[0.5, -1.25]
        radius = 2.5
        pgon = nsidedpoly(6; Center=center, Radius=radius)

        @test numsides(pgon) == 6
        @test collect(centroid(pgon)) ≈ center

        x, y = boundary(pgon)
        vertex_radii = hypot.(x[1:(end - 1)] .- center[1], y[1:(end - 1)] .- center[2])
        @test length(vertex_radii) == 6
        @test all(r -> isapprox(r, radius), vertex_radii)
    end

    @testset "有效 Float64 SideLength" begin
        side_length = 1.5
        pgon = nsidedpoly(5; SideLength=side_length)
        x, y = boundary(pgon)
        vertices = hcat(x[1:(end - 1)], y[1:(end - 1)])
        next_vertices = vertices[[2:end; 1], :]
        edge_lengths = hypot.(
            next_vertices[:, 1] .- vertices[:, 1],
            next_vertices[:, 2] .- vertices[:, 2],
        )

        @test numsides(pgon) == 5
        @test length(edge_lengths) == 5
        @test all(d -> isapprox(d, side_length), edge_lengths)
    end

    @testset "正常范围宽整数和任意精度实数" begin
        bigint_polygon = nsidedpoly(BigInt(7))
        unsigned_polygon = nsidedpoly(UInt8(6))
        bigfloat_center = BigFloat[big"0.25", big"-0.75"]
        bigfloat_radius = big"1.25"
        bigfloat_polygon =
            nsidedpoly(4; Center=bigfloat_center, Radius=bigfloat_radius)

        @test numsides(bigint_polygon) == 7
        @test numsides(unsigned_polygon) == 6
        @test numsides(bigfloat_polygon) == 4
        @test collect(centroid(bigfloat_polygon)) ≈ Float64.(bigfloat_center)
    end

    @testset "有理数实值输入" begin
        rational_n_polygon = nsidedpoly(6 // 1)
        center = [1 // 2, -3 // 2]
        side_length = 3 // 2
        rational_polygon =
            nsidedpoly(5; Center=center, SideLength=side_length)
        x, y = boundary(rational_polygon)
        vertices = hcat(x[1:(end - 1)], y[1:(end - 1)])
        next_vertices = vertices[[2:end; 1], :]
        edge_lengths = hypot.(
            next_vertices[:, 1] .- vertices[:, 1],
            next_vertices[:, 2] .- vertices[:, 2],
        )

        @test numsides(rational_n_polygon) == 6
        @test numsides(rational_polygon) == 5
        @test collect(centroid(rational_polygon)) ≈ Float64.(center)
        @test all(d -> isapprox(d, Float64(side_length)), edge_lengths)
    end

    @testset "显式默认值和空中心验证" begin
        implicit_defaults = nsidedpoly(4)
        explicit_defaults =
            nsidedpoly(4; Center=Float64[0.0, 0.0], Radius=1.0)

        @test _open_boundary(explicit_defaults) ≈
            _open_boundary(implicit_defaults)
        @test_throws ErrorException nsidedpoly(4; Center=Float64[])
    end
```
