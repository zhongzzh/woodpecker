### 文档自身缺陷审计

- `tspan` 声明为“向量”，但示例 `[0 5]` 在 Julia 中为 1×2 Matrix，结构描述与示例不一致。
- `y0` 声明为“向量”，但示例含 `y0=0` 标量和 `y0=-5:5` UnitRange；数据类型仅写 `Int | Float`，但示例 eg7 使用复数。
- `odefun` 正文要求“必须返回列向量 dydt”，但示例 eg1 返回标量 `2*t`，前后矛盾。
- 语法块多处写作 `[t,y, = ode45(...)]`，尾逗号易被读作笔误。
- “y0 的类型需要和 odefun 函数返回类型保持一致”表述过强；test11 中 odefun 返回实标量而 y0 为复数仍可运行，应说明为类型兼容或可提升。
- `output_sol=true` 示例与警告冲突，未同步为推荐的 `ReturnStruct`。
- `options` 小节写“结构体数组”，实际应为单个 OdeOption 结构体。

### 覆盖缺口与优先级

**高优先级**

- tspan 递减区间或递减多元素向量：文档明确允许单调递减，现有测试全部递增，递减路径无任何覆盖。建议补测 `[1.0,0.0]` 或 `[5.0,3.0,1.0]`，断言时间方向和解值。
- odefun 返回复数且 y0 为复数：文档 eg7 展示 `odefun=(t,y)->1im*y`，当前 test11 仅覆盖 y0 复数、odefun 实数，未覆盖真正复数 odefun。建议补测 `1im*y` 场景并断言类型和解析值。
- Float 列向量 y0 的强断言：目前仅 test8 弱证据，test3 为 Matrix。建议补测 Float 列向量并用线性方程解析解断言。

**中优先级**

- options 的 `stats=:on`：文档示例明确，但无任何覆盖。建议补测 `odeset(; stats=:on)` 并做数值断言。
- options 的 `nonnegative=[1]`：test9 仅 `@test_nowarn`，无结果断言。建议补强非负性质断言。
- Complex 向量 y0：文档示例仅复数标量，但复数初始条件语义下向量缺口存在。建议与复数 odefun 配套补测。
- `[0 5]` Matrix 写法与文档“向量”冲突：非测试缺口，但应通过文档或测试说明结构，避免误判。

**低优先级**

- 多中间点对 InitialStep、MaxStep 的影响：文档说明较多，现有多元素测试只覆盖简单恒等方程，未验证与二元素区间差异。可补非恒定方程多中间点性质测试。
- mass 回调的强断言：test8 为弱证据；若需完整覆盖回调型质量矩阵，可补强结果断言。
- sol.xe、sol.ye、sol.ie 事件结构体字段：输出结构体事件字段未覆盖，但属于输出参数完整性，可作为低优先级。

### 缺失测试代码补全

```julia
@testset "ode45 补充" begin
    @testset "tspan 单调递减" begin
        t, y = ode45((t, y) -> 1.0, [1.0, 0.0], 0.0)
        @test issorted(vec(t); rev=true)
        @test isapprox(vec(y), vec(t) .- 1.0; atol=1e-10, rtol=1e-10)
    end

    @testset "odefun 返回复数且 y0 为复数" begin
        odefun = (t, y) -> 1im * y
        t, y = ode45(odefun, [0.0, 1.0], 1.0 + 0im)
        @test eltype(y) <: Complex
        @test isapprox(y[end], exp(1im * t[end]); atol=1e-8, rtol=1e-8)
    end

    @testset "Float 列向量 y0 强断言" begin
        odefun = (t, y) -> [1.0, -1.0]
        t, y = ode45(odefun, [0.0, 1.0], [0.0, 1.0])
        @test size(y, 2) == 2
        @test isapprox(vec(y[:, 1]), vec(t); atol=1e-10, rtol=1e-10)
        @test isapprox(vec(y[:, 2]), 1.0 .- vec(t); atol=1e-10, rtol=1e-10)
    end

    @testset "options stats 与 nonnegative 补强" begin
        opts_stats = odeset(; stats=:on)
        t1, y1 = ode45((t, y) -> -y, [0.0, 1.0], 1.0, opts_stats)
        @test isapprox(y1[end], exp(-t1[end]); atol=1e-6, rtol=1e-6)

        opts_nn = odeset(; nonnegative=[1])
        t2, y2 = ode45((t, y) -> -abs.(y), [0.0, 1.0], 1.0, opts_nn)
        @test minimum(vec(y2)) >= -1e-12
    end

    @testset "Complex 向量 y0" begin
        odefun = (t, y) -> [1im * y[1], 1im * y[2]]
        t, y = ode45(odefun, [0.0, 1.0], [1.0 + 0im, 0.0 + 1im])
        @test eltype(y) <: Complex
        @test isapprox(y[end, 1], exp(1im * t[end]); atol=1e-8, rtol=1e-8)
        @test isapprox(y[end, 2], 1im * exp(1im * t[end]); atol=1e-8, rtol=1e-8)
    end
end
```

**静态检验说明**：本代码块是一个独立的顶层 `@testset "ode45 补充"`，只依赖文件顶部已导入的 Test、TyDifferentialEquation、TyMathCore 以及全局可用的 ode45、odeset，未引用任何原有测试块内部局部变量，可整体追加到目标测试文件 ode45.jl 的物理末尾；没有插入、改写或复述原有测试代码。

**仍需 baseline 校准项**：

- 数值容差为经验值，应在实际运行后根据求解器默认容差校准；尤其复数 odefun 终点断言建议先跑通基线。
- 递减 tspan 的 `issorted(rev=true)` 需确认求解器返回点顺序与 tspan 方向一致。
- options stats 可能会打印统计信息，CI 中若日志过冗可关闭或改为 `@test_nowarn`。
- Complex 向量 y0 测试假设实现支持复数向量初值；若不支持，应将该子测试改为文档支持范围内的场景或拆分。
