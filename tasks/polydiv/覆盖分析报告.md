### ❌ 缺失覆盖的细颗粒度差异清单

1. **完全未覆盖的参数**：无（b、a 均有大量用例）。
2. **「结构形式」缺失的漏测点**：
   - b 为**整型行向量**（如 `[1 2 3]`）：整型只测过列向量（逗号语法 Vector）和标量；
   - b 为**复数行向量**：复数只测过列向量；
   - a 为**整型行向量**；
   - a 为**复数行向量**；
   - b 与 a **方向混搭**（一个行向量、一个列向量）：文档说两参数各自"行或列向量"，未定义混搭时输出方向——此项**预期行为不明，不能直接补测**，见补全模块末尾说明。
3. **「数据类型」缺失的漏测点**：
   - **实数混合类型**：b 为 Float、a 为 Int（或反之）从未同时出现（现有用例要么全 Float，要么全 Int，复数用例倒是混了 Complex{Int} 与 ComplexF64）；

@testset "AI_polydiv_integer_row_vectors" begin
    q, r = polydiv([1 2 3], [1 1])
    @test q == [1.0 1.0]
    @test r == [0.0 0.0 2.0]

    @test q == [1.0 1.0]
    @test r == [0.0 0.0 2.0]
end

@testset "AI_polydiv_complex_row_vectors" begin
    q, r = polydiv([1+2im -3+4im 2-im], [1-im 2+0.5im])
    @test q ≈ [-0.5+1.5im -1.25+0.0im]
    @test r ≈ [0.0+0.0im 0.0+0.0im 4.5-0.375im]
end

@testset "AI_polydiv_mixed_real_types" begin
    q, r = polydiv([2.0, -3.0, 4.0, -5.0], [1, -2, 1])
    @test q == [2.0, 1.0]
    @test r == [0.0, 0.0, 4.0, -6.0]

    q, r = polydiv([1, 2, 3], [1.0, 1.0])
    @test q == [1.0, 1.0]
    @test r == [0.0, 0.0, 2.0]

- 预期值来源：`[1 2 3] ÷ [1 1]` 与 `Int32` 列向量用例（`AI_polydiv_scalar_and_integer`）同系数，商余为 `[1,1]`/`[0,0,2]`；复数行向量与 `AI_polydiv_complex` 同系数；混合类型与 `AI_polydiv_remainder` 首例同系数——全部沿用原文件已验证过的数值，只变换方向或元素类型。行向量输入 → 行向量输出的取向依据是原文件 `AI_polydiv_exact_division` 与 `AI_polydiv_matrix_vector_inputs`（1×N 进 1×N 出）的既有断言。
- **方向混搭（b 行 a 列）未补**：文档没有定义混搭时 q、r 的方向，凭空断言会变成"猜实现"；建议先用 MATLAB `deconv` 跑同参数确认预期方向后再补（列入待办），这符合"expected 无正确答案时不瞎写"的原则。
