- 语法中的 `R, = radon(I)` 和 `R, = radon(I,theta)`容易被理解为函数只返回一个结果，但实现始终返回二元组 `(R, xp)`；文档应明确这是忽略第二个返回值的解构写法。
- `theta` 的结构说明是“数值向量”，数据类型却仅列出 `Int64`，两者范围不一致。“数值向量”通常还会包含其他整数类型及浮点向量。
- 示例使用 `theta = 0:180`，默认角度则声明为 `0:179`。自定义角度可以包含 180 度，但文档没有解释示例为何比默认范围多一个周期等价角度，容易造成默认范围前后不一致的印象。
- `0:179` 和 `0:180` 的元素类型是平台相关的 `Int`；将其无条件记录为 `Int64`，在非 64 位平台上不严谨。
- 实现允许标量 `theta`、任意维 `AbstractArray` 角度并将其展平，也允许浮点角度、空角度和非有限角度，但这些调用形式与行为未写入文档。

- 实现签名中的 `MInteger`、`MFloat` 所涵盖类型是否严格等于文档列出的五种数值类型没有说明，文档类型范围与实现约束缺少对应关系。

- 文档没有说明 `theta` 的二维或更高维数组是否属于受支持输入，也没有说明实现会按线性顺序展平。

### 覆盖缺口与优先级

**高优先级**

- UInt8、UInt16、Int16、Float32 图像均只有 1×1 单点证据，无法覆盖非单点矩阵的行列遍历、零像素跳过、多个非零像素累加及不同角度投影。建议使用同一幅至少 2×3 的可精确转换图像，分别构造四种类型，并断言形状、xp、投影总和及与 Float64 基准的一致性。
- 非单点整数图像目前没有结果证据。尤其 UInt8、UInt16 无法表示负值，Int16 可以表示负值；建议先使用所有类型共有的非负图像完成跨类型比较，再为 Int16 单独增加包含负值的性质测试。

**中优先级**

- 文档示例的显式 `0:180` Int64 范围没有直接测试。默认调用只执行内部 `0:179`，不能替代用户显式传入范围。建议增加显式范围调用，断言结果有 181 列、xp 形状正确且每个有限角度的投影总和保持不变。
- 非平凡图像测试主要依赖投影总和、反向关系及同一实现生成的列比较，尚无独立实现或可信参考库提供的逐元素基准。建议使用 MATLAB、ImageTransformations 兼容实现或解析可验证图形生成 baseline 后，再加入逐元素近似断言。

**低优先级**

- 浮点角度矩阵、空浮点向量、整数标量和非有限角度已有测试，但这些形式未被文档公开声明。应先决定将其正式写入文档还是明确标记为非公开扩展，再决定是否纳入正式输入覆盖指标。
- Bool 图像已有完整调用和断言，但文档未列出 Bool。建议统一文档和实现后再将其计入公开类型覆盖。
- 零行、零列图像及角度数组维度展平行为未形成公开约束。应先确定预期支持范围，避免根据当前实现偶然行为编写固定测试。

### 缺失测试代码补全

```julia
@testset "radon 补充覆盖" begin
    @testset "non-single documented image element types" begin
        base_I = Float64[
            1 0 2
            0 3 1
        ]
        theta = Int64[0, 45, 90, 135]
        baseline_R, baseline_xp = radon(base_I, theta)

        @test size(baseline_R) == (7, length(theta))
        @test size(baseline_xp) == (7, 1)
        @test vec(baseline_xp) == collect(-3.0:3.0)
        @test vec(sum(baseline_R; dims=1)) ≈ fill(sum(base_I), length(theta))

        for T in (UInt8, UInt16, Int16, Float32)
            typed_I = T.(base_I)
            R, xp = radon(typed_I, theta)

            @test size(R) == size(baseline_R)
            @test size(xp) == size(baseline_xp)
            @test eltype(R) == Float64
            @test xp == baseline_xp
            @test R ≈ baseline_R
            @test vec(sum(R; dims=1)) ≈ fill(Float64(sum(typed_I)), length(theta))
        end
    end

    @testset "signed Int16 non-single image" begin
        I = Int16[
             1  0
            -2  3
        ]
        theta = Int64[0, 90, 180, 270]
        R, xp = radon(I, theta)

        @test size(R) == (7, length(theta))
        @test size(xp) == (7, 1)
        @test vec(xp) == collect(-3.0:3.0)
        @test vec(sum(R; dims=1)) ≈ fill(Float64(sum(I)), length(theta))
        @test R[:, 2] ≈ reverse(R[:, 1])
        @test R[:, 4] ≈ reverse(R[:, 3])
    end

    @testset "explicit documented integer range" begin
        I = Float64[
            1 0
            0 1
        ]
        theta = 0:180
        R, xp = radon(I, theta)

        @test size(R) == (7, length(theta))
        @test size(xp) == (7, 1)
        @test vec(xp) == collect(-3.0:3.0)
        @test vec(sum(R; dims=1)) ≈ fill(sum(I), length(theta))
        @test R[:, end] ≈ reverse(R[:, 1])
    end
end
```
