### 文档自身缺陷审计

- 语法部分使用 `nodeIDs`，输入参数标题及说明使用 `nodeID`，存在命名不一致。
- 第一个示例标题为“确定命名节点的索引”，但示例图中未创建命名节点，标题与内容不符。
- 文档未明确 `rmnode!` 的返回值及原地修改的具体语义（例如是否返回图本身或 `nothing`）。
- 文档未描述删除不存在节点、越界索引、非正索引、重复 ID 等边界行为；测试中对越界 ID 静默忽略、非正 ID 报错，但这些约束未在文档中声明。
- 输入参数 `G` 的示例 `G = Graph(1,2)` 与 `G = DiGraph([1,2],[2,3])` 中 `Graph(1,2)` 的构造形式未在文档其他部分说明，可能引起歧义。

### 覆盖缺口与优先级

**高优先级**

- `rmnode!` 函数完全没有测试：文档声明了 `rmnode!(G, nodeIDs)` 原地删除，但提供的测试文件中未出现任何 `rmnode!` 调用。缺少 `rmnode!` 对 `G` 和 `nodeID` 两个参数的覆盖，也未验证原地修改、不产生新图、节点编号更新及边删除行为。

**中优先级**

- `DiGraph` 带名称的节点删除未覆盖：测试中 `Gd` 是无名称有向图，`G3` 是无向带名称图，未组合覆盖有向图 + 节点名称删除。文档示例中展示了 `DiGraph(s, t, Float64[], names)` 的带名称有向图，建议补充。
- 名称数组混合有效/无效名称的正常删除路径未覆盖：现有 `rmnode(G2, ["a", "hxjhj"])` 仅触发异常，未测试“部分名称存在、部分不存在”时删除有效项并忽略无效项的结果；整数混合路径已有 `rmnode(Gd, [3, 10])` 覆盖。

**低优先级**

- 空节点 ID 数组（删除 0 个节点）未测试，边界行为未知。
- 删除所有节点的极限情况未测试，无法确认空图行为。
- 非整数数值索引（如 `Float64(1.0)`）未测试，但文档未明确允许，暂不列为必须。

### 缺失测试代码补全

```julia
@testset "rmnode! 补充" begin
    s = [1, 1, 1, 2, 2, 3, 3, 4, 5, 5, 6, 7]
    t = [2, 4, 8, 3, 7, 4, 6, 5, 6, 8, 7, 8]
    name = ["a", "b", "c", "d", "e", "f", "g", "h"]
    nodeprop = [1, 2, 3, 4, 5, 6, 7, 8]
    weight = ones(Int, 12)
    edgeprop = zeros(Int, 12)

    @testset "无向图原地删除索引节点" begin
        G_expected = Graph(s, t, weight, name, nodeprop, edgeprop)
        H_expected = rmnode(G_expected, 2)
        G_mut = Graph(s, t, weight, name, nodeprop, edgeprop)
        rmnode!(G_mut, 2)
        @test isEqualG(
            G_mut,
            H_expected.Nodes.nodeNames,
            H_expected.Nodes.props,
            H_expected.Edges.endnodes,
            H_expected.Edges.weights,
            H_expected.Edges.props,
        )
        @test numnodes(G_mut) == 7
        @test numedges(G_mut) == 9
    end

    @testset "有向图原地删除索引向量" begin
        Gd_expected = DiGraph(s, t)
        Hd_expected = rmnode(Gd_expected, [7, 5])
        Gd_mut = DiGraph(s, t)
        rmnode!(Gd_mut, [7, 5])
        @test Gd_mut.Nodes.nodeNames == Hd_expected.Nodes.nodeNames
        @test Gd_mut.Edges.endnodes == Hd_expected.Edges.endnodes
        @test Gd_mut.Edges.weights == Hd_expected.Edges.weights
        @test Gd_mut.Edges.props == Hd_expected.Edges.props
        @test numnodes(Gd_mut) == 6
        @test numedges(Gd_mut) == 6
    end

    @testset "带名称无向图原地删除名称数组" begin
        G_expected = Graph(s, t, weight, name, nodeprop, edgeprop)
        H_expected = rmnode(G_expected, ["b", "e"])
        G_mut = Graph(s, t, weight, name, nodeprop, edgeprop)
        rmnode!(G_mut, ["b", "e"])
        @test isEqualG(
            G_mut,
            H_expected.Nodes.nodeNames,
            H_expected.Nodes.props,
            H_expected.Edges.endnodes,
            H_expected.Edges.weights,
            H_expected.Edges.props,
        )
        @test numnodes(G_mut) == 6
        @test numedges(G_mut) == 6
    end

    @testset "重复 ID 原地删除按集合语义" begin
        Gd_mut = DiGraph(s, t)
        Gd_single = DiGraph(s, t)
        rmnode!(Gd_mut, [3, 3])
        Hd_single = rmnode(Gd_single, 3)
        @test Gd_mut.Nodes.nodeNames == Hd_single.Nodes.nodeNames
        @test Gd_mut.Edges.endnodes == Hd_single.Edges.endnodes
        @test numnodes(Gd_mut) == 7
    end
end
```
