### 文档定义的输入参数

| 参数 | 允许形式 | 允许数据类型 | 说明 |

### 文档自身缺陷审计

- `delimiter` 写明数据类型含 `Symbol`，但「示例」仅给出 `','`、`"comma"`、`'\t'`、`"tab"`，未给出 `Symbol` 示例。
- 语法块未写出单/双位置参数形式与 `toworkspace` 默认组合的完整关系；`tdfread(filename)` / `tdfread(filename, delimiter)` 的默认返回 `nothing` 只在说明中出现。
- 输出 `s` 描述了 `Vector{Float64}` / `Vector{ComplexF64}` / `Vector{String}` 与空字段 `NaN`，但输入节未对应说明「可计算数值表达式列」的解析规则与失败回退为字符串，约束不完整。
- 文档未描述字段数不匹配、`delimiter` 空符号、非法 `toworkspace` 类型等报错约定，与实现/测试中的 `ArgumentError`/`TypeError`/`MethodError` 不对齐。
- 链接路径中 `DescripitiveStatistics` 疑似拼写错误（不影响参数语义）。

### 参数数据类型与结构覆盖

#### filename

| 数据类型或结构 | 说明 | 对应测试用例位置 | 覆盖状态 |
| --- | --- | --- | --- |
| String（mktemp 绝对路径） | 构造临时文件、调用、断言列值/类型 | `tdfread.jl`：`_tdfread_from_string`；`tdfread: toworkspace 到 Main` 内 `tdfread(filename, "comma")` | ☑ |
| 相对路径 | 文档允许相对路径 | 无 | 未覆盖 |
| 当前目录仅文件名 | 文档允许当前目录文件名 | 无 | 未覆盖 |
| 其他 AbstractString（如 SubString） | 文档类型为 AbstractString | 无 | 未覆盖 |

说明：路径证据以 `mktemp` 产生的 `String` 为主，属于强证据；但未区分相对路径/纯文件名，也未覆盖非 `String` 的 `AbstractString` 子类型。

#### delimiter

| 数据类型或结构 | 说明 | 对应测试用例位置 | 覆盖状态 |
| --- | --- | --- | --- |
| 默认不传入（tab） | 助手默认 `"tab"`；无 delimiter 调用 | `tdfread.jl`：`_tdfread_from_string("A\tB\n1\t2\n")`；`tdfread: 可计算列` 第二例 | ☑ |
| String 等效名称 tab/space/comma/semi/bar | 五类名称 | `tdfread: delimiter 与字符串列` 中 `aliases` 含 `delimiter.name` | ☑ |
| Symbol 等效名称 | `:tab` 等 | 同上，`Symbol(delimiter.name)` | ☑ |
| Char 分隔符 | `' '`、`'\t'`、`','`、`';'`、`'|'` | 同上，`delimiter.character` | ☑ |
| String 单字符 | `" "`、`"\t"`、`","` 等 | 同上，`string(delimiter.character)` | ☑ |
| 非标准字符串（首字符+警告） | `"::"` → `':'` | `tdfread: 空文件、delimiter 回退与报错` 中 `@test_logs ... "::"` | ☑ |
| 空 String `""` | 回退/边界 | 同上，`_tdfread_from_string(..., "")` | ☑ |
| 空 Symbol `Symbol("")` | 显式报错 | 同上，`@test_throws ArgumentError ... Symbol("")` | ☑ |
| tab 别名 `"\\t"` | 额外别名 | `tdfread: delimiter 与字符串列` 对 tab `push!(aliases, "\\t")` | ☑ |

说明：五类标准分隔符在名称/Symbol/Char/单字符 String 上均有「构造、调用、断言」链，覆盖较强。`default` 路径通过不传或助手默认体现；非默认值已由显式别名覆盖，不依赖默认推断。

#### toworkspace

| 数据类型或结构 | 说明 | 对应测试用例位置 | 覆盖状态 |
| --- | --- | --- | --- |
| 默认 Val(true)（不传关键字） | 写入 Main、打印摘要、返回 nothing | `tdfread: toworkspace 到 Main` 中 `tdfread(filename, "comma")` | ☑ |
| 显式 Val(true) | 关键字传入 | 同文件 `toworkspace=Val(true)`（含 Base 冲突与空文件分支） | ☑ |
| 显式 Val(false) | 返回命名元组且不写 Main | `_tdfread_from_string` 默认；`TdfreadNotExported` 断言 `!isdefined(Main, ...)` | ☑ |
| 非法类型 Bool false | `TypeError` | `tdfread: 空文件、delimiter 回退与报错` 中 `toworkspace=false` | ☑ |

说明：`Val(true)`/`Val(false)` 均有结果断言（Main 变量、返回值、摘要文本），为强覆盖。非法类型属边界，已覆盖。

### 覆盖缺口与优先级

**高优先级**

- 无。三个输入参数的核心类型与文档表内 delimiter 形态均已有构造+调用+断言证据。

**中优先级**

- `filename` 相对路径与「当前目录仅文件名」：现有证据全是临时绝对路径，不能证明文档写明的另外两种路径形式；建议在测试中 `cd` 到临时目录后传纯文件名/相对路径并断言列内容。
- 文档 `Symbol` 示例缺失：功能已被测试覆盖，但文档应补 `Symbol(:comma)` 一类示例，避免类型表与示例不一致。

**低优先级**

- `filename` 的非 `String` `AbstractString`（如 `SubString`）：文档写 AbstractString，现实调用多为 String；可补一条 `tdfread(SubString(path, 1, length(path)), ...)`。
- 非法关键字（如 `bad=Val(false)` → `MethodError`）已测，属实现边界，不计入文档输入覆盖缺口。

### 缺失测试代码补全

```julia
@testset "tdfread: filename 路径形式补缺" begin
    # 复用原风格：临时目录 + 逗号分隔小表，断言命名元组内容与类型
    mktempdir() do dir
        content = "Name,Score\nAlice,1.5\nBob,2.5\n"
        filename = joinpath(dir, "tdfread_rel.dat")
        write(filename, content)

        # 1) 当前目录仅文件名
        old = pwd()
        try
            cd(dir)
            result = tdfread("tdfread_rel.dat", "comma"; toworkspace=Val(false))
            @test result.Name == ["Alice", "Bob"]
            @test result.Score == [1.5, 2.5]
            @test result.Name isa Vector{String}
            @test result.Score isa Vector{Float64}
        finally
            cd(old)
        end

        # 2) 相对路径（相对当前工作目录）
        parent = dirname(dir)
        base = basename(dir)
        old = pwd()
        try
            cd(parent)
            rel = joinpath(base, "tdfread_rel.dat")
            result = tdfread(rel, ','; toworkspace=Val(false))
            @test result.Name == ["Alice", "Bob"]
            @test result.Score == [1.5, 2.5]
        finally
            cd(old)
        end

        # 3) 其他 AbstractString：SubString 路径
        full = filename
        sub = SubString(full, 1, lastindex(full))
        @test sub isa AbstractString && !(sub isa String)
        result = tdfread(sub, Symbol("comma"); toworkspace=Val(false))
        @test result.Name == ["Alice", "Bob"]
        @test result.Score ≈ [1.5, 2.5]
        @test result isa NamedTuple
    end
end
```

**静态检验说明**

- 补测仅针对 `filename` 未覆盖的路径形态与 `AbstractString` 子类型；`delimiter`/`toworkspace` 无高优先级缺口，未重复堆叠。
- 风格对齐原文件：`mktempdir`/`tdfread(..., toworkspace=Val(false))`、列值与 `isa` 断言；未使用 TODO 或省略号。
- 期望值来自写入的确定文本（`Alice/Bob`、`1.5/2.5`），不依赖外部 baseline 数值文件。

**仍需 baseline 校准项**

- 无必须 baseline 校准的精确浮点/摘要字节项；若实现对象系统路径规范化（符号链接、`\\`/`/`）与本补测环境不一致，需在目标 OS 上实跑确认相对路径分支。
