### 覆盖缺口与优先级

**高优先级**

- c 的向量、矩阵以及 `trisurf(T,x,y,z,c)`、`trisurf(TR,c)` 重载完全没有调用证据；应分别构造同元素数量的 c，调用后至少断言返回对象非空，并为颜色语义建立图像 baseline。
- ConstrainedTriangulation 完全未覆盖；应使用项目中真实的约束三角剖分构造 API 创建三维对象，分别测试省略 c 和显式 c 的重载。
- facecolor 和 edgecolor 的全部用户可设置形式均未显式覆盖；默认调用不能证明字符串特殊值、颜色名称、RGB 三元组和十六进制代码可用。
- 当前没有非法输入测试；T 的非三列、非正索引和越界索引，以及 x、y、z、c 元素数量不一致时的异常契约均未得到验证。

**中优先级**

- facealpha 没有显式测试 0、1 和区间内部值；应断言调用成功，并在可查询属性稳定后断言实际属性值。
- linestyle 的五个枚举值均未显式覆盖；应逐值传入并断言返回对象存在，视觉差异仍需 baseline。
- linewidth 没有显式非默认正值测试，也没有零值和负值的异常测试。
- T 主要由 delaunay 间接构造；应增加一个字面量三列整数矩阵直接调用 trisurf 的测试，以隔离 trisurf 对 T 的处理。

**低优先级**

- 现有 TR 测试没有显式类型断言，类型证据依赖 `triangulation` 构造函数契约。
- x、y、z 已覆盖向量和矩阵，但没有覆盖整数坐标、混合数值类型、非标准 `AbstractVector` 或非标准 `AbstractMatrix`。
- 现有测试以图像比较为主，没有验证返回补片对象的公开类型和属性；文档需先明确稳定的输出类型及属性访问接口。

@testset "trisurf 补充覆盖" begin
    T = [
        1 2 3
        1 3 4
    ]
    x_vector = [0.0, 1.0, 1.0, 0.0]
    y_vector = [0.0, 0.0, 1.0, 1.0]
    z_vector = [0.0, 0.5, 1.0, 0.25]
    c_vector = [0.1, 0.4, 0.8, 0.2]

    x_matrix = reshape(copy(x_vector), 2, 2)
    y_matrix = reshape(copy(y_vector), 2, 2)
    z_matrix = reshape(copy(z_vector), 2, 2)
    c_matrix = reshape(copy(c_vector), 2, 2)

    function assert_patch_created(args...; kwargs...)
        h = trisurf(args...; kwargs...)
        @test h !== nothing
        return h
    end

    @testset "显式顶点颜色数据" begin
        h_vector_c = assert_patch_created(
            T,
            x_vector,
            y_vector,
            z_vector,
            c_vector,
        )
        @test h_vector_c !== nothing

        h_matrix_c = assert_patch_created(
            T,
            x_matrix,
            y_matrix,
            z_matrix,
            c_matrix,
        )
        @test h_matrix_c !== nothing

        tr = triangulation(T, x_vector, y_vector, z_vector)
        h_tr_c = assert_patch_created(tr, c_vector)
        @test h_tr_c !== nothing
    end

    @testset "facecolor 允许形式" begin
        facecolors = (
            "flat",
            "none",
            "yellow",
            [0.2, 0.4, 0.6],
            "#336699",
        )
        for facecolor_value in facecolors
            h = assert_patch_created(
                T,
                x_vector,
                y_vector,
                z_vector;
                facecolor=facecolor_value,
            )
            @test h !== nothing
        end
    end

    @testset "facealpha 范围" begin
        facealpha_values = (0.0, 0.35, 1.0)
        for facealpha_value in facealpha_values
            h = assert_patch_created(
                T,
                x_vector,
                y_vector,
                z_vector;
                facealpha=facealpha_value,
            )
            @test h !== nothing
        end
    end

    @testset "edgecolor 允许形式" begin
        edgecolors = (
            [0, 0, 0],
            "none",
            "red",
            [0.2, 0.4, 0.6],
            "#336699",

                T,
                x_vector,
                y_vector,
                z_vector;
                edgecolor=edgecolor_value,
            )
            @test h !== nothing
        end
    end

    @testset "linewidth 正值" begin
        linewidth_values = (0.1, 0.5, 2.0)
        for linewidth_value in linewidth_values
            h = assert_patch_created(
                T,
                x_vector,

                z_vector;
                linewidth=linewidth_value,
            )
            @test h !== nothing
        end
    end

    @testset "linestyle 枚举值" begin
        linestyles = ("-", "--", ":", "-.", "none")
        for linestyle_value in linestyles
            h = assert_patch_created(
                T,
                x_vector,
                y_vector,
                z_vector;
                linestyle=linestyle_value,
