### 文档自身缺陷审计

- 文档将 `h` 描述为“补片对象”，同时又标注为“标量”，两者语义不一致；应明确其实际返回类型或抽象对象类型。
- 文档没有明确 `T` 的具体元素类型，只说明索引为正整数；也没有明确矩阵是否必须为二维稠密矩阵。
- 文档没有明确 x、y、z、c 的元素类型、是否允许整数、浮点数或其他实数类型。
- 文档说明 x、y、z 具有相同数量的元素，但没有说明矩阵输入的形状是否必须相同，还是只要求线性元素数量相同。
- 文档说明 `TR` 可以是 `ConstrainedTriangulation`，但示例和测试只展示了 `Triangulation`，缺少约束三角剖分对象的构造示例。
- `facecolor` 和 `edgecolor` 的 RGB 三元组没有说明分量范围，例如是否必须位于 [0,1]。
- 名称-值参数的错误值、越界值和类型错误行为没有说明。
- `facecolor` 的默认值 `"flat"` 和未指定 `c` 时 z 兼作颜色数据的关系描述不够完整，未明确指定 c 时的颜色映射规则。

### 覆盖缺口与优先级

#### 高优先级

- `ConstrainedTriangulation` 未覆盖。现有测试只有 `Triangulation`，不能据此证明约束三角剖分对象路径可用；建议按项目实际公开构造 API 创建包含三维点的约束对象，调用 `trisurf(TR)` 和 `trisurf(TR,c)`，并断言结果类型或可查询属性。
- `facecolor="none"` 未覆盖。现有测试覆盖颜色名称、RGB 和十六进制代码，但没有该文档声明的特殊字符串值；建议显式调用并断言返回对象及面颜色属性。
- `linestyle="none"` 未覆盖。现有测试覆盖其余四种线型，但没有不显示边线的路径；建议显式调用并断言线型属性或可验证的绘图性质。
- 名称-值属性缺少实际属性断言。`!== nothing` 只能证明调用返回了某个值，不能证明 facecolor、facealpha、edgecolor、linewidth 和 linestyle 被正确应用；建议在补片对象支持的公开属性接口上逐项查询并断言。

#### 中优先级

- x、y、z、c 的元素类型没有覆盖矩阵和向量的具体数值类型。文档本身未规定具体元素类型，现有代码也没有类型断言；建议先明确文档契约，再补充整数、浮点数等允许类型的构造、调用和结果断言。
- c 的测试始终复用 z 的数据，缺少数值不同但元素数量相同的独立颜色数据；建议构造独立的向量和矩阵颜色数据，并验证结果属性或稳定的图像基线。
- 缺少尺寸约束测试。x、y、z 数量不一致、c 与 z 数量不一致、T 索引越界和 T 列数错误均没有测试；建议按实际 API 的异常类型或异常性质补充异常断言。
- facealpha 只覆盖 0、0.5、1，未覆盖其他合法值和越界值；建议补充中间浮点值以及非法边界的异常或拒绝行为。

#### 低优先级

- 未显式测试 facecolor、edgecolor、linewidth 和 linestyle 的默认值属性。默认路径已经被执行，但默认值没有被查询断言；建议显式传入文档列出的默认值或读取返回对象属性。
- 未覆盖空对象、单三角形或最小合法输入结构；单点、空对象等场景不能由当前网格和随机数据测试替代。
- RGB 三元组分量范围、十六进制颜色格式合法性及颜色名称大小写规则没有文档约束或测试；建议先补全文档契约，再增加合法和非法格式测试。
