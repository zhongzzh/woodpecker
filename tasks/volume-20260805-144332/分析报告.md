- `RegionID` 的具体类型边界不明确。现有测试覆盖了 `Int` 标量、`Float64` 整数值标量、范围和 `Int` 矩阵，但没有明确验证普通 `Vector{Int}` 以及其他 Julia 整数类型。建议补测普通整数向量，并对返回结果断言为向量且尺寸与输入一致。
- 文档未说明 `RegionID` 数组的维度保持规则。现有矩阵测试已提供证据，但普通向量尚未直接构造和断言，建议补充。

#### 中优先级

- 未测试空整数数组，例如 `Int[]`。文档只要求正整数数组，没有说明空数组应返回空结果还是报错，建议先明确接口约束，再补充对应结果或异常断言。
- 未测试 `Int32`、`UInt` 等其他整数类型。若文档中的“整数”意指 Julia `Integer`，建议至少覆盖一种非默认 `Int` 的整数类型。

#### 低优先级

- 未测试包含重复合法区域 ID 的普通向量之外的更多数组形态。现有矩阵 `[1 1; 2 2]` 已覆盖重复 ID，剩余价值较低。

        10.3 0.0 0.0
        10.0 0.3 0.0
        10.0 0.0 0.3
    ]
    shp = alphaShape(P3d, 1.0)

    region_ids = Int[1, 3]
    region_volumes = volume(shp, region_ids)
    @test region_volumes isa AbstractVector
    @test size(region_volumes) == size(region_ids)
    @test isapprox(
        region_volumes,
        [0.166666666666667, 0.00450000000000001];
        rtol=1e-14,

    @test region_volumes_int32 isa AbstractVector
    @test size(region_volumes_int32) == size(region_ids_int32)
    @test isapprox(
        region_volumes_int32,
        [0.166666666666667, 0.00450000000000001];
